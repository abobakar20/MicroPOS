# MicroPOS

A modern mobile Point of Sale (POS) application built with React Native and Expo.

## Features

- 🛒 **POS Screen** – Fast checkout with product grid and cart
- 📦 **Products** – Manage your product catalog with categories
- 📋 **Orders** – View order history and details
- 📊 **Reports** – Daily/weekly sales analytics and charts

## Getting Started

```bash
npm install
npx expo start
```

## Tech Stack

- React Native + Expo
- Expo Router (file-based navigation)
- Zustand (state management)
- AsyncStorage (local persistence)
- React Native Chart Kit (charts)
